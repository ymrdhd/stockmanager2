# 业务验收与自动化测试矩阵

> Agent 实现每一个流程时就要补上对应测试，不得在最后阶段一次性补测。下面是最低门槛，不是可选项。

## A. 交易与批次（P1 阻断发布）

| ID | 场景 | 必须满足 |
|---|---|---|
| T01 | 同 `request_id` 重复提交相同买单 | 仅一笔成交、一笔现金变化；返回相同结果 |
| T02 | 同 `request_id` 请求内容不同 | 409 冲突，不修改任何事实 |
| T03 | 买入提交后模拟进程崩溃并重启 | 成交/持仓/资金全部存在或全部不存在 |
| T04 | 买入交易中途故意制造约束失败 | 整个事务回滚，不出现“有持仓无成交” |
| T05 | 卖出超量或错误批次 | 拒绝且不扣减其他批次 |
| T06 | 主仓与加仓子仓分别卖出 | 剩余数量、冻结 ATR 和策略批次身份正确 |
| T07 | 两笔价格/日期/数量恰好相同、券商 ID 不同 | 两笔均有效，不误去重 |
| T08 | 冲正历史交易再更正 | 旧事实保留审计，新投影重算，原记录不可无痕覆盖 |

## B. 收益与证券账户（P1 阻断发布）

| ID | 场景 | 必须满足 |
|---|---|---|
| P01 | 只刷新页面、重启服务或重算当日收益 N 次 | 原始成交与现金流不变，收益不重复累计 |
| P02 | 昨持仓 + 今日买卖 + 交易费用 | 逐笔解释性 P&L 与权益法在规定误差内一致 |
| P03 | 今日买入后又全部卖出 | 已实现收益正确，剩余持仓为零 |
| P04 | 证券账户入金 | 证券权益增加、投资 P&L 不增加 |
| P05 | 银行→证券账户内部转账 | 个人净资产不变、普通收入不变 |
| P06 | 缺少昨收或行情源过期 | `unavailable/stale`，不显示虚假 0 或正式信号 |
| P07 | 补录三天前的真实成交 | 从受影响日期后重算，不对现有收益再叠增量 |
| P08 | ETF 拆分/现金分红（有明细输入时） | 数量、成本/现金、收益口径可解释，不凭价格跳变虚构收益 |

## C. 财务（P2 阻断发布）

| ID | 场景 | 必须满足 |
|---|---|---|
| F01 | 22 日 23:59 与 23 日 00:00 的不同财务月 | 进入正确分期（含跨年/闰年） |
| F02 | `manual_snapshot` 账户录入普通支出 | 普通账单保存，但账户余额不自动重复扣减 |
| F03 | 更正账户手工余额 | 写审计与调整；不产生虚构收入 |
| F04 | 证券市值投影到个人总资产 | 证券账户权益不重复计入 |
| F05 | 净资产跨天重算 | 同一事实与报价版本结果一致 |
| F06 | 旧 Finance 迁移测试 | 账户余额、财务月总额及历史审计可核对 |

## D. 策略与行情（P1/P3 阻断发布）

| ID | 场景 | 必须满足 |
|---|---|---|
| S01 | V9/G2 相同历史输入/规则版本 | 与被确认的旧有效黄金样例输出一致 |
| S02 | 当日盘中预测/候选 vs 收盘正式信号 | 严格区分，不生成正式成交或已执行记录 |
| S03 | 额外因子不可验证/行情过期 | 正式准入拒绝，显示原因 |
| S04 | ETF 代理行情或指数点位与 ETF 价格混用 | 禁止用于正式 ETF 交易价 |
| S05 | 冻结 ATR 随后行情更新 | 已有批次 ATR 不发生无依据改变 |
| S06（V1.5） | Fed 数据源失效 | 显示上次有效时间/不可用，不自动改 V9/G2 裁决 |

## E. 单库 / 双机 / 备份（P0/P3 阻断发布）

| ID | 场景 | 必须满足 |
|---|---|---|
| I01 | 配置正式库路径不存在 | 拒绝启动正式写服务，不默默创建空库 |
| I02 | 正式库 UUID/role 与配置不一致 | fail closed，界面展示安全错误 |
| I03 | 公司服务不可连接 | 家里只显示离线，不自动向本地正式库写入 |
| I04 | 同时启动第二个正式 writer | 第二个不能启动正式写入/任务调度 |
| I05 | 公司与家里浏览器访问同一服务 | 相同 ledger/quote 版本返回相同持仓/盈亏/净资产 |
| I06 | 在线一致性备份 + 隔离恢复 | `integrity_check` 和业务对账通过 |
| I07 | 备份中出现私钥、token、账本 ZIP | 路径过滤排除已知敏感路径；人工检查内容及排除项 |
| I08 | 恢复旧 snapshot 后切换实例 | 有实际隔离旧写端的证据；仅 generation 不足；无法确认则拒绝接管 |

## F. Agent / 工程工具（每轮必测）

- `python -m unittest discover -s tests/tooling -v`：打包脚本测试（新增/修改/删除、路径安全、禁止敏感文件、文件校验）。
- `python -m compileall -q backend tools`（`backend` 存在后）；`ruff check .`、`pytest -q`（对应模块实现后）。
- 审查 ZIP 检查：必须运行 `python tools/verify_review.py <ZIP>`；含 `manifest.json`、`REVIEW.md`、本轮文件的 SHA256；不存在 `.env`、数据库、密钥、缓存、日志。
- 未运行的命令如实写 `NOT RUN: 原因`，禁止写假绿。

## G. 发布门槛

- P0：I01/I02/I04 和工具测试通过；无正式数据泄漏。
- P1：A/B/D 中 V1.0 适用用例通过（S06 延至 V1.5），交易与收益核心无已知不一致；新旧策略对照报告留档。
- P2：C 组及 F06 通过；历史账务差异有人工核对记录。
- P3：E 组全通过；实际异地访问测试、安全测试、恢复演练通过。
- P4：有真实旧库时对账签字并锁定旧写入口；无旧库只能标记“尚未完成迁移验证”。

## H. 补充阻断用例（对应阶段必须通过）

| ID | 场景 | 预期 | 阶段 |
|---|---|---|---|
| T09 | 券商稳定 ID 重复导入、请求不同 | 幂等或冲突，不重复成交 | P1 |
| T10 | 已实际成交偏离策略/缺 ATR | 保留事实和待核对原因，不伪造策略状态 | P1 |
| P09 | 并发刷新与成交、行情版本变化 | 投影版本一致或失效重算 | P1 |
| P10 | 初始持仓、历史缺口、费用未知 | 不伪造成交或收益，缺口可见 | P1 |
| F07 | 手工账户转账及已包含历史余额 | 不重复扣款，转账不算收入 | P2 |
| S07 | 盘中/历史计算试图访问未来行情 | 不生成正式信号，固定 as_of | P1 |
| S08 | 版本升级与旧批次 | 冻结数据/旧证据不漂移 | P1 |
| I09 | 未授权、Host/Origin/CSRF/WS、伪造代理头 | 拒绝访问或写入 | P3 |
| I10 | 旧主机失联但无停写证据 | 拒绝接管，不产生双主 | P3 |
| I11 | 升级失败；切换后已有新成交 | 安全阻断；不覆盖丢失新事实 | P4 |
| I12 | 审查包校验被篡改或额外文件 | 验证失败；无真实数据外发 | 每轮 |
| UI01–09（按版本适用） | 见 INTERFACE_CONTRACT 功能覆盖与 E2E | 真实入口及操作成功/失败路径 | P3 |

V1.0 排除 ADR-013 明确延期的功能验收（UI05、UI01 的分钟图/ETF 等权线及高级图表、UI06/UI08 精细财务图表与界面优化）；其余适用核心业务、安全及数据验收不豁免。I06 在 01-db-identity 仅验证基础一致性备份；完整隔离恢复与业务对账仍为发布门槛。APPROVED_WITH_ISSUES 不改变任何实际测试结果。

所有适用阻断 ID 以实际执行结果为准，阶段表中的旧 ID 范围是最低集合，不豁免本节。
