# 09F 产品口径决策记录（候选，未正式批准）

依据 PRODUCT_SPEC、INTERFACE_CONTRACT、09D 审查、原始参考 ZIP 的 Finance 实际源码及 09F 任务书。原始参考 ZIP 未修改。以下均待产品及独立审查；不改变 V9/G2/ATR/动态3/10日冷却公式。

| 事项 | 证据/候选口径 | 需确认或限制 |
|---|---|---|
| 退款 | 原 Finance `subroutine/finance/transaction_service.py` 44–56、117–167、960–1004 及 `period_spending.py` 148–180：关联原支出/累计上限、冲减原支出期间。09F 保留原期支出冲减；实际收到退款另记到账月 `refund_received_fen`/`bill_cash_flow_fen`，不计收入。独立正数账单、关联原支出、现金收款账户、幂等、更正/作废，原支出有有效退款时拒绝直接冲正；手工余额不自动更新。 | 与建议退款发生月直接冲减冲突，不擅自替换。旧库含 REFUND/REIMBURSEMENT 仍需迁移映射与独立对账，不默认迁入。普通财务账户现只允许 manual_snapshot，不能虚构 ledger 模式。 |
| 基础当日投资收益率 | 统一 PortfolioService：当日正式盈亏 / 上一有效交易日收盘权益 ×100；同事务同版本；总体采用总体分子分母。 | 非 TWR/MWR；缺失、非正分母、非交易日返回不可计算。产品确认口径与显示精度。 |
| 流动净资产 | 原 Finance `subroutine/finance/balance_sheet_service.py` 153–160、289–317：流动资产减流动负债，不能把长期负债统一归流动。2.0 可识别银行/现金/支付/证券权益和信用卡；其他资产/其他负债分类不清时不计算完整指标。证券现金和持仓通过证券权益仅计一次。 | 与建议全部统计负债扣除冲突。尚无受限资金/其他类别的可审计历史分类入口，需确认分类方案；已知部分不得冒充完整金额。 |
| 接近止损 | 仅展示预警，默认 200 bps（2%），`start.py server --near-stop-bps 0..1000` 配置；使用有效证券未复权行情及账本核实的 ATR 仓证据，已达保护价优先，已有模型退出不覆盖；T5 排除。 | 候选阈值非策略参数；当前测试仅边界函数及既有策略回归，尚需实际主/子仓、过期报价专项与浏览器验证。 |
| 财务健康 | 展示流动资金、负债、净资产和财务月收支事实；无综合评分。 | 质量信息仍需逐金额完善，避免零代未知；产品确认流动口径后才冻结。 |
